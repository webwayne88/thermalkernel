# ThermalKernel

Открытое детерминированное ядро тепловой защиты зданий по **СП 50.13330.2012**.

Каждый результат сопровождается ссылкой на конкретный пункт СП. Ядро не обращается к сети, не использует LLM и не имеет побочных эффектов — только расчёт.

**Архитектурный паттерн:** Trusted Kernel + LLM Conductor. Ядро считает, LLM переводит намерение пользователя в вызовы ядра и объясняет результат. LLM сам ничего не вычисляет.

---

## Статус: v0.2.0, alpha. Этап 1–2

Реализовано:
- расчёт по СП 50.13330 (R₀_усл, R₀_пр, ГСОП, R_норм, вердикт);
- мостики холода: коэффициент теплотехнической однородности r через `Construction.r_coef`, R₀_пр = R₀_усл · r;
- трансмиссионные теплопотери Q_тр по каждой ограждающей конструкции;
- инфильтрационные теплопотери Q_инф (упрощённая модель);
- удельный расход тепловой энергии на отопление q_уд — полная формула: теплопотери минус бытовые теплопоступления с коэффициентом авторегулирования, делённые на КПД системы отопления, кВт·ч/(м²·год);
- класс энергоэффективности (A++…F) по отклонению от базового расхода;
- CLI, Python API.

**Нормативно не валидирован.** Коэффициенты и пороги классов являются предварительными — см. раздел «Ограничения и валидация».

В планах (следующие этапы): LLM-оркестратор (Conductor), FastAPI, веб-UI, экспорт нормоотчёта.

Требования: Python 3.10+, pydantic v2.

```bash

pip install -e .
```

```bash
pip install thermalkernel  # после публикации — пока недоступно
```

## Быстрый старт

### CLI

```bash
# Газобетон 400 мм, Новосибирск (параметры по умолчанию)
python -m thermalkernel

# Явные параметры
python -m thermalkernel --material gazobeton --thickness 400 --city novosibirsk

# Кирпич 510 мм, Москва, tв = 22 °C
python -m thermalkernel --material kirpich_keramicheskiy --thickness 510 --city moscow --t-in 22

# Список доступных материалов
python -m thermalkernel --list-materials

# Список доступных городов
python -m thermalkernel --list-cities

# Расчёт здания — встроенный демо-пример
python -m thermalkernel --demo-building

# Расчёт здания из JSON-файла
python -m thermalkernel --building building.json
```

Ключи аргументов: `--material` / `-m`, `--thickness` / `-d` (мм), `--city` / `-c`, `--type` / `-t` (wall|roof|floor|window), `--t-in` (°C, по умолчанию 20), `--condition` (A|B, по умолчанию B).

Класс F в демо объясняется намеренно слабым остеклением (одинарное стекло, R₀_пр ≈ 0,17 м²·°C/Вт) — это учебный пример, демонстрирующий, как окна доминируют в теплопотерях. С нормальным двухкамерным стеклопакетом (R₀_пр ≈ 0,51) класс поднимается до C–D.

### Python API

```python
from thermalkernel import (
    evaluate,
    evaluate_building,
    Construction,
    ConstructionType,
    Layer,
    Climate,
    Building,
    BuildingType,
    BuildingResult,
    OperationCondition,
)
from thermalkernel.data import load_materials, load_climate, load_coefficients, get_material, get_climate

materials = load_materials()
climates = load_climate()
coefficients = load_coefficients()

# --- Расчёт одной конструкции ---
climate = get_climate("novosibirsk", climates)

construction = Construction(
    type=ConstructionType.WALL,
    layers=[Layer(material="gazobeton", thickness=0.4)],  # толщина в метрах
    area=1.0,
    # r_coef=1.0 по умолчанию — мостики холода не учитываются
    # r_coef=0.85 — задать вручную, если есть результат теплотехнического расчёта
)

result = evaluate(construction, climate, t_v=20.0, materials=materials, coefficients=coefficients)

print(result.verdict)           # "не соответствует"
print(result.r0_pr)             # приведённое сопротивление, м²·°C/Вт
print(result.r_norm)            # нормируемое сопротивление, м²·°C/Вт
print(result.gsop)              # ГСОП, °C·сут
print(result.required_extra_insulation_mm)  # дефицит в мм минваты (λ=0.06, усл.Б)
print(result.sp_refs)           # список ссылок на пункты СП

# --- Расчёт здания ---
building = Building(
    city="moscow",
    building_type=BuildingType.RESIDENTIAL,
    floors=3,
    t_v=20.0,
    heated_area=600.0,
    heated_volume=1800.0,
    constructions=[
        Construction(
            type=ConstructionType.WALL,
            layers=[
                Layer(material="kirpich_keramicheskiy", thickness=0.51),
                Layer(material="minvata", thickness=0.10),
            ],
            area=300.0,
            operation_condition=OperationCondition.B,
            r_coef=0.9,  # мостики холода: задать по расчёту конструктива или оставить 1.0
        ),
        # ... остальные конструкции
    ],
)

br: BuildingResult = evaluate_building(building, get_climate("moscow", climates), materials, coefficients)

print(br.specific_heat_demand)      # q_уд, кВт·ч/(м²·год)
print(br.normative_heat_demand)     # q_норм, кВт·ч/(м²·год)
print(br.energy_class)              # класс энергоэффективности, например "F"
print(br.q_total_w)                 # суммарные теплопотери, Вт
print(br.q_losses_kwh)              # теплопотери за период, кВт·ч/год
print(br.q_internal_gains_kwh)      # бытовые теплопоступления, кВт·ч/год
print(br.q_net_kwh)                 # нетто-потребность в тепле, кВт·ч/год
```

## Что считает ядро

### Расчёт ограждающей конструкции

| Величина | Формула | Ссылка на СП |
|----------|---------|--------------|
| Термическое сопротивление слоя | R = δ / λ | СП 50, п. 8.4, ф. (8.4) |
| Условное сопротивление теплопередаче | R₀_усл = 1/αв + ΣR + 1/αн | СП 50, п. 8.1, ф. (8.1) |
| Приведённое сопротивление | R₀_пр = R₀_усл · r | СП 50, прил. Е, п. Е.1 |
| Градусо-сутки отопительного периода | ГСОП = (tв − tот) · zот | СП 50, п. 5.3, ф. (5.2) |
| Нормируемое сопротивление | R_норм = a · ГСОП + b | СП 50, п. 5.3, табл. 3 |
| Вердикт соответствия | R₀_пр >= R_норм | СП 50, п. 5.3 |

Коэффициенты поверхностной теплоотдачи: αв = 8,7 Вт/(м²·°C), αн = 23 Вт/(м²·°C) — СП 50, п. 8.1, табл. 4 и 6.

Коэффициент теплотехнической однородности r задаётся в `Construction.r_coef` (по умолчанию 1,0 — мостики холода не учитываются). Значение r < 1,0 пользователь задаёт самостоятельно по результатам расчёта конструктива.

### Расчёт здания

| Величина | Формула / модель | Ссылка на СП |
|----------|-----------------|--------------|
| Трансмиссионные теплопотери | Q_тр_i = A_i · (tв − t5) · n_i / R₀_пр_i | СП 50, п. 9.1 |
| Инфильтрационные теплопотери | Q_инф = c_в · ρ_в · V · n_ин · (tв − t5) / 3600 | СП 60, п. 8 |
| Теплопотери за период | Q_потери = Q_сум · z_от · 24 / 1000, кВт·ч/год | СП 50, п. 10.1 |
| Бытовые теплопоступления | Q_быт = q_внутр · A_от · z_от · 24 / 1000, кВт·ч/год | СП 50, п. 10.1 |
| Нетто-потребность в тепле | Q_нетто = (Q_потери − Q_быт · v_r) / eta_sys | СП 50, п. 10.1 |
| Удельный расход тепла на отопление | q_уд = Q_нетто / A_от | СП 50, п. 10.1 |
| Нормируемый удельный расход | q_норм = f(тип здания, этажность) | СП 50, прил. Б |
| Класс энергоэффективности | δ = (q_уд − q_норм) / q_норм → класс A++…F | СП 50, прил. Б, табл. Б.1 |

Обозначения: q_внутр — удельные бытовые теплопоступления, Вт/м²; v_r — коэффициент авторегулирования (учёт использования теплопоступлений); eta_sys — КПД системы отопления. Значения берутся из `coefficients.json`.

```
thermalkernel/
    __init__.py         # публичный API v0.2.0: evaluate(), evaluate_building(), модели
    calc.py             # расчётная логика (чистые функции)

    cli.py              # CLI
    __main__.py         # точка входа python -m thermalkernel
    data/
        materials.json      # справочник материалов (λ по условиям А/Б)
        climate.json        # климатология городов (t5, t_от, z_от)
        coefficients.json   # αв/αн, a/b, n_инф, q_внутр, v_r, eta_sys,
                            #   базовые удельные расходы по типу/этажности
        energy_classes.json # пороги классов энергоэффективности A++…F
```

## Ограничения и валидация

**Предварительные коэффициенты.** Значения в `coefficients.json` (пороги классов энергоэффективности, базовые удельные расходы по типу/этажности — аналог табл. 13 СП 50, кратность инфильтрации n_ин, бытовые теплопоступления q_внутр, КПД системы отопления eta_sys, коэффициент авторегулирования v_r) являются предварительными. Требуется сверка с официальным текстом СП 50.13330.2012. Номера пунктов и формул в `refs.py` также требуют проверки.

**Мостики холода.** `Construction.r_coef` по умолчанию равен 1,0 — влияние мостиков холода не учитывается. Конкретное значение r < 1,0 пользователь задаёт самостоятельно на основании расчёта конструктива (методика по СП 50, прил. Е или СП 23-101).

**Инфильтрация.** Упрощённая модель кратности воздухообмена. Детальный расчёт с учётом ветрового давления по СП 60.13330.2020, п. 8 не реализован.

**Отсутствие эталонных примеров.** Эталонных расчётов СП 23-101 в проекте нет. Тесты — ручные поверки самосогласованности. Числовая точность результатов не верифицирована по официальным примерам нормативных документов.

**Необходима валидация.** Перед применением результатов в проектной документации **требуется проверка практикующим экспертом-теплотехником**.

**Многослойные конструкции в CLI.** Через CLI задаётся один слой; программный API принимает произвольное число слоёв.

## Дисклеймер

Инструмент носит **расчётно-вспомогательный** характер и **не заменяет проектную документацию, проходящую государственную экспертизу**. Ответственность за итоговый проект несёт проектировщик.

Справочные данные (λ материалов, климатические параметры, коэффициенты) структурированы авторами на основе СП 50.13330.2012, СП 131.13330 и СП 23-101. Дословные таблицы из нормативных документов не воспроизводятся; ссылка на источник указана для каждого значения.
