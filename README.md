# ThermalKernel

Открытое детерминированное ядро тепловой защиты зданий по **СП 50.13330.2012**.

Каждый результат сопровождается ссылкой на конкретный пункт СП. Ядро не обращается к сети, не использует LLM и не имеет побочных эффектов — только расчёт.

**Архитектурный паттерн:** Trusted Kernel + LLM Conductor. Ядро считает, LLM переводит намерение пользователя в вызовы ядра и объясняет результат. LLM сам ничего не вычисляет.

---

## Статус: Этап 0-1. Голое ядро

Реализовано: расчёт по СП 50.13330 (R₀_усл, R₀_пр, ГСОП, R_норм, вердикт), CLI, Python API.

В планах (следующие этапы): расширение ядра (теплопотери, класс энергоэффективности), LLM-оркестратор (Conductor), FastAPI, веб-UI, экспорт нормоотчёта.

## Быстрый старт

### CLI

```bash
# Газобетон 400 мм, Новосибирск (параметры по умолчанию)
python -m thermalkernel

# Явные параметры
python -m thermalkernel --material gazobeton --thickness 400 --city novosibirsk

# Кирпич 510 мм, Москва, tв = 22 °C
python -m thermalkernel --material kirpich_keramicheskiy --thickness 510 --city moscow --t-in 22

# Список доступных материалов
python -m thermalkernel --list-materials

# Список доступных городов
python -m thermalkernel --list-cities
```

Ключи аргументов: `--material` / `-m`, `--thickness` / `-d` (мм), `--city` / `-c`, `--type` / `-t` (wall|roof|floor|window), `--t-in` (°C, по умолчанию 20), `--condition` (A|B, по умолчанию B).

Пример вывода для газобетона 400 мм, Новосибирск, стена, условие Б, tв = 20 °C:

```

  СП 50.13330.2012
============================================================

ИСХОДНЫЕ ДАННЫЕ
  Конструкция : wall
  Слой        : Газобетон, δ = 400 мм
  Условие экспл.: B
  Город       : Новосибирск
  tв          : 20.0 °C
  tот         : -8.7 °C  (отопит. период)
  zот         : 230 сут.

РЕЗУЛЬТАТЫ РАСЧЁТА

  Слой 1: R = δ/λ = 0.400 / 0.1800 = 2.2222 м²·°C/Вт
    Ref: СП 50.13330.2012, п. 8.4, формула (8.4)

         = 1/8.7 + 2.2222 + 1/23.0
         = 2.3812 м²·°C/Вт

         = 0.00035 × 6601.0 + 1.4
         = 3.7104 м²·°C/Вт

------------------------------------------------------------
  Проверка: R₀_пр (2.3812) >= Rнорм (3.7104) ?
  ВЕРДИКТ : НЕ СООТВЕТСТВУЕТ
```

### Python API

```python
from thermalkernel import evaluate, Construction, ConstructionType, Layer, Climate
from thermalkernel.data import load_materials, load_climate, load_coefficients, get_material, get_climate

materials = load_materials()
climates = load_climate()
coefficients = load_coefficients()

climate = get_climate("novosibirsk", climates)

construction = Construction(
    type=ConstructionType.WALL,
    layers=[Layer(material="gazobeton", thickness=0.4)],  # толщина в метрах
)

result = evaluate(construction, climate, t_v=20.0, materials=materials, coefficients=coefficients)

print(result.verdict)           # "не соответствует"
print(result.r0_pr)             # приведённое сопротивление, м²·°C/Вт
print(result.r_norm)            # нормируемое сопротивление, м²·°C/Вт
print(result.gsop)              # ГСОП, °C·сут
print(result.required_extra_insulation_mm)  # дефицит в мм минваты (λ=0.06, усл.Б)
print(result.sp_refs)           # список ссылок на пункты СП
```

## Что считает ядро

| Величина | Формула | Ссылка на СП |
|----------|---------|--------------|
| Термическое сопротивление слоя | R = δ / λ | СП 50, п. 8.4, ф. (8.4) |
| Условное сопротивление теплопередаче | R₀_усл = 1/αв + ΣR + 1/αн | СП 50, п. 8.1, ф. (8.1) |
| Приведённое сопротивление | R₀_пр = R₀_усл · r | СП 50, прил. Е, п. Е.1 |
| Градусо-сутки отопительного периода | ГСОП = (tв − tот) · zот | СП 50, п. 5.3, ф. (5.2) |
| Нормируемое сопротивление | R_норм = a · ГСОП + b | СП 50, п. 5.3, табл. 3 |
| Вердикт соответствия | R₀_пр >= R_норм | СП 50, п. 5.3 |

Коэффициенты поверхностной теплоотдачи: αв = 8,7 Вт/(м²·°C), αн = 23 Вт/(м²·°C) — СП 50, п. 8.1, табл. 4 и 6.

Коэффициенты a, b для типов конструкций (стена, покрытие, перекрытие, окно) — СП 50, п. 5.3, табл. 3.


## Ограничения и валидация

- Справочники `materials.json`, `climate.json`, `coefficients.json` и номера пунктов СП в `refs.py` являются **предварительными**. Требуется сверка с официальным текстом СП 50.13330.2012 и эталонными примерами СП 23-101 «Проектирование тепловой защиты зданий» до использования в боевых расчётах.
- Мостики холода: коэффициент теплотехнической однородности r = 1,0 (влияние мостиков холода не учитывается). Полный учёт — Этап 2.
- Многослойные конструкции в CLI — один слой; программный API принимает произвольное число слоёв.
- **Требуется валидация практикующим экспертом-теплотехником** до применения результатов в проектной документации, сдаваемой на экспертизу.

## Дисклеймер

Инструмент носит **расчётно-вспомогательный** характер и **не заменяет проектную документацию, проходящую государственную экспертизу**. Ответственность за итоговый проект несёт проектировщик.

Справочные данные (λ материалов, климатические параметры, коэффициенты) структурированы авторами на основе СП 50.13330.2012, СП 131.13330 и СП 23-101. Дословные таблицы из нормативных документов не воспроизводятся; ссылка на источник указана для каждого значения.
